# Диалог с нейросетью: Изучение Git и Python

В этом файле зафиксирован мой путь общения с ИИ в процессе выполнения задания. Я делал всё самостоятельно по шагам, разбираясь в каждой ошибке.

## Пошаговый процесс работы:

1. **Теория:** Мы разобрали, что такое Git. Я узнал, что это система контроля версий (кнопка «Сохранить» для кода).
2. **Разница между репозиториями:**
   * *Локальный:* Хранится на моем ПК, помнит историю изменений.
   * *Облачный:* Хранится на серверах GitHub для бэкапа и совместной работы.
3. **Настройка VS Code:** 
   * Отключили безопасный режим (*Restricted Mode*).
   * Установили расширения для Python.
   * Установили движок Python в систему, исправили переменные окружения (PATH).
4. **Написание кода:** В файле `main.py` я запрограммировал игру «Угадай число» с использованием циклов `while True` и условий `if/elif/else`. Программа успешно отлажена и работает.
5. **Магия Git в Терминале:**
   * Инициализировал репозиторий: `git init` (появились зеленые буквы U - Untracked).
   * Настроил имя и почту автора через `git config`.
   * Добавил файлы в индекс `git add .` (буквы сменились на A) и сделал первый коммит `git commit -m "First commit"`.
6. **Борьба с облаком (GitHub):**
   * Создал пустой репозиторий на сайте.
   * Столкнулся с тем, что автопереводчик Яндекса обрезал ссылки в браузере. Мы победили его, введя адрес вручную!
   * Исправил опечатку в никнейме (пересчитали девятки — их ровно 10: `bebrabebra9999999999-ai`).
   * Привязал правильный адрес через `git remote add origin` и успешно отправил код командой `git push -u origin main` после прохождения авторизации в браузере!
