# Моя первая программа и изучение Git

## Что такое Git?
Git (Гит) — это локальная система контроля версий. Она работает как «кнопка сохранения» в видеоиграх. Git запоминает каждое изменение в коде и позволяет в любой момент вернуться к старой рабочей версии, если что-то сломалось.

## Локальный и Облачный репозиторий: в чём разница?
* **Локальный репозиторий** — это вся история изменений кода, которая хранится прямо на моём компьютере. Можно работать даже без интернета.
* **Облачный репозиторий** — это копия проекта на сервере в интернете (например, на GitVerse или GitHub). Нужен для резервного копирования и чтобы показывать код другим разработчикам.

## Моя программа
В файле `main.py` написана мини-игра «Угадай число» на языке Python. Компьютер загадывает случайное число, а пользователь пытается его угадать с помощью подсказок.
